# M1 世界設定筆記：失時方舟／帆尾眠鼯

我想做的世界是一艘接近光速航行的巨大生態船。人類管理者早已消失，但森林、蓄水池與自動維修系統仍在運作。動物不知道自己身在太空，只知道某一片森林會亮起、變暖，另一片則逐漸進入寒冷的暗季。

主角暫名「帆尾眠鼯」，是蜜袋鼯族群的後代。牠展開像帆一樣的滑翔膜，在樹冠與維修架之間移動；休息時縮成毛球，利用短暫休眠節省能量，再跟著照明季節遷移。

> 牠們追逐的不是太陽，而是一艘無人方舟最後還亮著的森林。

相對論、旋轉人工重力和蜜袋鼯的滑翔、短暫休眠都有科學依據；方舟、帆尾眠鼯以及下文的年代、尺寸、溫度、繁殖數字是創作設定，不是研究預測。

## 1. 年代：船上經過一萬年，故鄉已過約十萬年

### 過了多久？人造物變成什麼樣子？

- **時間：**以人類管理者消失為起點，方舟在船上時間裡繼續航行約 10,000 年。假設巡航速度是出發地參考系中的約 99.5% 光速，忽略加減速與重力效應，該參考系約經過 100,000 年。這符合狹義相對論的時間膨脹關係。[1]
- **不是慢動作：**船內生物的心跳、思考與成長仍然正常。牠們只有船上的一萬年能繁衍，不會多得到船外那九萬年的演化時間。船上收到故鄉的影像也不是單純快轉十倍，還受到訊號延遲與都卜勒效應影響。
- **祖先：**人類原先把蜜袋鼯帶進保存艙。祖先已具有滑翔膜、樹棲能力與雜食性，所以我沿著原有構造發展，不讓牠突然長出另一對翅膀。[2] 一萬年不保證必定形成新物種，因此先把牠當作特化的後代族群。
- **人工地形：**森林長在旋轉圓筒的內壁，樹木朝中央方向生長。維修架、管道與廢棄步道形成第二套樹冠，各區用保持氣壓的通道連接。
- **人造物：**燈具、管線與密封件靠機器更換，外殼與支架持續修補，不是所有零件一萬年都不會壞。
- **必要假設：**方舟擁有長期能源、散熱、原料回收、無人維修、輻射與高速塵粒防護，也能維持足夠大的動植物族群。這些都是遠超現有能力的工程前提，不能只靠「有 AI」就成立。

## 2. 環境：光照會遷移，往中央爬會比較輕

### 溫度、光、水、空氣與危險是什麼？

- **人工重力：**暫設圓筒半徑約一公里，旋轉使內壁約有 0.6 倍地球重力。對跟著艙體旋轉、停在支架上的動物，越靠近轉軸，有效重力越小。旋轉居住艙有研究基礎，但這種完整方舟尚不存在。[3]
- **重力的限制：**一般樹梢只高幾十公尺，與地面的差異不會非常大。要沿數百公尺高的維修架向中央爬，才會明顯改變。離架後的運動還涉及原本速度、空氣和旋轉效應，不是靠近中央就能隨意漂浮。
- **照明季節：**能源系統老化，部分森林進入高照度生長期，其他區域進入節能暗季。季節以數週到數月移動，相鄰區重疊照明一段時間；每個區域仍保留約 24 小時的明暗週期。
- **植物的限制：**亮燈不會立刻長出食物，動物要等食物增加才遷入。暗季保留低功率維生照明，植物偏向耐陰或能休眠的種類，不設定整片森林長期全黑卻永遠不死。
- **溫度：**明季約 20–27°C，暗季約 12–18°C。暖管附近可避寒，但太靠近散熱設備會燙傷。
- **水與空氣：**冷凝水、灌溉水與廢水經處理循環。植物提供部分食物與氧氣，仍需通風、污染物處理和備用設備。真實太空植物研究支持部分功能，並未證明萬年封閉生態系已可行。[4]
- **主要危險：**停電、漏氣、風扇吸入口、通道關閉、污染累積和食物減少。牠只能在有氣壓的艙內生存。

## 3. 生存：會滑翔、會省能的活風箏

### 吃什麼？特殊能力有什麼用？被誰吃？

主要能量路徑是：**方舟能源系統 → 植物燈 → 植物 → 昆蟲與帆尾眠鼯**。牠吃果實、花蜜、樹液與昆蟲，延伸自蜜袋鼯祖先的食性。[2] 牠本身不會光合作用，也不能直接吃電。

我設定牠軀幹約 18–22 公分，尾巴接近身長，身上有灰白短毛、深色滑翔膜和扁長的尾毛。張開時像小風箏，收起時像一顆毛球。

| 特徵 | 生存用途 | 代價與限制 |
| --- | --- | --- |
| 四肢之間的滑翔膜 | 從高處跨越樹冠與支架空隙 | 不能主動拍翅飛行；金屬邊緣可能劃傷膜 |
| 扁長、毛蓬鬆的尾巴 | 協助調整滑翔姿態 | 不是推進器，不能無限升高 |
| 彎曲腳爪與抓握後足 | 停靠樹皮、繩索和網架 | 不能吸附所有光滑金屬面，也怕被夾住 |
| 大眼睛、耳朵與觸鬚 | 在暗處辨認障礙與路徑 | 無法透視、預知故障或操控時間 |
| 短暫休眠 | 寒冷、食物少時降低代謝 | 仍需能量和水；甦醒有成本，反應遲緩時容易被捕食 |

短暫休眠的靈感來自蜜袋鼯研究，野外個體能依環境調整活動與低代謝狀態。[5] 我設定眠鼯一次休眠以數小時為主，不是不吃不喝睡幾十年。

牠會學習固定路線上的氣流，但通風不一定能托住牠。滑翔仍需合適高度和降落點；在旋轉艙體裡，路徑也不能直接照搬地球環境。

掠食者暫設為保存艙中小型貓頭鷹的後代，前提是方舟夠大、獵物量足夠。眠鼯最怕的是照明排程突然改變：記住的路線可能通往已經沒食物的冷區。

## 4. 棲息：在森林與機械之間遷移

### 住哪裡？群居還是獨居？何時活動？

- **住處：**明暗季交界附近的樹洞、乾燥檢修盒與停用管道，避開風扇、漏水點和活動中的機械。
- **群居：**暫設每群約 4–8 隻，休息時聚集保溫，覓食時分散。好處是共用藏身處，代價是競爭、疾病，以及巢位故障時整群受影響。
- **一天的活動：**偏向局部熄燈後覓食，白天休息。牠追逐的是有食物的照明季節，不是一直往最亮的燈泡飛。
- **遷移：**新區域食物增加後，有個體先探索，再逐步換巢。路線靠學習、氣味與環境線索，不是出生就知道整艘船的地圖。
- **立體棲地：**沿維修架爬高，再滑向別處；向中央延伸的支架提供不同有效重力的移動環境，但中央食物少，不適合一直居住。

我最想畫的場景：局部燈光熄滅後，一群眠鼯依序從舊指示牌上展膜滑出，穿過樹冠和生鏽的維修架。休息時，牠們像毛球一樣縮在檢修盒裡。

## 5. 繁殖：把幼體帶著走，跟上移動的季節

### 怎麼生？多久一代？下一代會不會變異？

- **方式：**保留有袋類的有性生殖與胎生。幼體出生時發育尚不完全，進入母體育兒袋繼續發育、吸乳，不是產卵。[2]
- **數量：**暫設每胎 1–2 隻，每年約一胎，食物充足時才可能有第二胎。這是眠鼯的設計值，不直接當成蜜袋鼯的固定數據。
- **育兒袋的用途：**早期幼體能隨母獸換巢，但負重會降低滑翔靈活度，因此母獸需要較短、安全的路線。較大的幼體仍需安全巢位，不能永遠裝在袋裡遷移。
- **繁殖季：**傾向在食物增加時育幼。牠不能預知管理程式，只能依循過往規律；排程突變會讓繁殖失敗。
- **照護與休眠的衝突：**哺乳需要能量，不能假設母獸可毫無代價地帶幼體長時間休眠。育幼期間優先找暖巢、持續覓食並減少休眠。
- **多久一代：**暫設約一歲半到兩歲可能開始繁殖；這不是平均世代長度，後者還要看不同年齡留下後代的情況。
- **遺傳與變異：**幼體繼承雙親特徵，重組與突變帶來差異。若體型、滑翔控制或耐受環境的特徵有可遺傳差異，才可能經長期選擇改變；具體路線則主要靠學習。

我希望牠可愛，又有一點末日感。牠不知道宇宙已經過了多久，只知道要在下一片森林熄燈前，找到能養大幼體的地方。
