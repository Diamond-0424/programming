## 操作導覽與物種觀察

1. **開啟方式**：直接以瀏覽器開啟本資料夾的 [`index.html`](file:///C:/Users/USER/OneDrive/Desktop/GitHub/programming/m2-species/index.html)。
2. **觀察重點**：
   - **高維截面**：預設是「斷環＋疊相」混合型。四組偏心斷弧有不同半徑、厚度、缺口與深度，搭配三層錯位輪廓及五個身體碎片。這是以深度控制的藝術化截面模型；原本四種解析幾何仍保留於 `legacy` 模式。
   - **待機／移動**：待機時停留原處、不同部位錯相呼吸；移動時自主朝路徑終點或獵物前進，深度起伏使局部截面縮放、斷裂與接回。穿越結束後仍會離開二維平面，再開始下一輪。
   - **感知／捕食**：感應附近節點，輪廓拉向獵物，碎片逐漸集中；鎖定後短暫蓄力與突進，斷環重新排列。只有真正閉合時仍在中央包圍內的獵物才被帶離，逃出去的節點可以存活。
   - **生態逃跑與捕食後恢復**：節點仍會感應各段截面並逃逸；捕食後疊相短暫劇烈錯位，再逐漸恢復。原本的殘影、漣漪、升維晶格淡出與累計帶離計數仍保留。
   - **世界環境共存**：承襲 M1 的二維幾何生態層，游離點隨資訊流運動、相近連成線、互連圍成面，與截游體形成動態生動的掠食與逃逸互動。
3. **互動控制**：
   - **連接距離／資訊流強度**：透過下方滑桿即時調節二維生態層的聚集密度與流向。
   - **點擊箱內**：在畫布任意位置點擊滑鼠，可投入一組新節點（5 顆）。
   - **暫停／重新生成／儲存截圖**：支援全域暫停、重設物種與即時匯出觀測圖。

## 造型與行為調整

參數集中在 `sketch.js` 上方的 `DRIFTER`。每次改一組參數、重新整理網頁，觀察差異。

| 想調整什麼 | 參數與預設 |
|---|---|
| 身體大小、多心弧形截面 | `size: 1`（建議 0.7～1.2）；`rings` 裡的 `radius`、`width`、`x/y`、`tilt`、`flatten`、`span`、`phase/depth`；各組有不同錨點與局部曲率中心 |
| 疊相層次 | `layers: 3`（建議 2～4）、`phaseOffset: 11`、`layerRotation: 0.3`、`layerWarp: 0.22`；分別控制位移、轉角與曲率差 |
| 呼吸與變形 | `breath: 0.065`、`breathRate: 1.45`、`deformation: 0.095` |
| 平滑隨機變化 | `morphAmount: 1` 控制幅度（建議 0～1.3）；`morphPeriod: 3.8` 控制基礎變化時間，越小越快，各部位仍不同步 |
| 身體碎片 | `fragments: 5`（建議 3～7），固定數量，不會不斷產生粒子 |
| 感知範圍與觀察時間 | `senseRadius: 175`、`senseTime: 0.6`、`feedReach: 115` |
| 蓄力與瞬間位移 | `windup: 0.18`、`burstTime: 0.22`、`burstDistance: 105` |
| 包圍與恢復 | `feedRadius: 43`、`closeTime: 0.65`、`recoveryTime: 1.1`、`cooldown: 1.8` |
| 巡游節奏與深度 | `moveSpeed: 27`、`idleTime: 1.3`、`moveTime: 3.8`、`depthWander: 0.12` |
| 取樣精細度／原版模式 | `arcSamples: 24`；`form: 'hybrid'`，改 `'legacy'` 可重現原本四種形態 |

時間以秒計，距離以 1000 × 460 的世界座標計；角度以弧度計。大幅增加尺寸或疊相偏移時，請重新檢查邊界。

程式分工：`computeHybridSections()` 建立造型、`displayBody()` 畫外觀、`updateMovement()` 控制移動與深度、`updateSensing()` 感知、`beginFeeding()`／`updateFeeding()` 包圍捕食、`updateHybrid()` 協調四種狀態。舊版幾何方法與捕食路徑保留。

固定狀態造型圖：[六種階段 PNG](previews/section-drifter-states.png)／[SVG](previews/section-drifter-states.svg)。這是從繪圖方法產生的離線造型圖，不是瀏覽器截圖；可用 `node tests/render-drifter.cjs` 更新 SVG。

驗證指令（在本資料夾執行）：`node --check sketch.js`、`node tests/drifter.cjs`。涵蓋四狀態、空缺與閉合、逃脫、相位恢復、暫停、原版幾何及 6,000 幀模擬。仍請親自打開網頁測試滑桿、點擊、暫停／繼續、重新生成與截圖，並確認動作節奏；本次瀏覽器目視驗證受工具限制未完成。
