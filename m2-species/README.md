## 操作導覽與物種觀察

1. **開啟方式**：直接以瀏覽器開啟本資料夾的 [`index.html`](file:///C:/Users/USER/OneDrive/Desktop/GitHub/programming/m2-species/index.html)。
2. **觀察重點**：
   - **高維截面**：截游體生活在三維空間，週期性穿透二維觀測平面。觀察畫面中淡線輪廓如何經歷「點狀出現 → 橢圓擴張 → 收腰 → 雙截面分離 → 接回 → 縮小消失」。
   - **追捕與覓食（Pursuit）**：截游體在三維巡游時感應二維獵物密集區（質心），平滑貝茲路徑與切面中心會柔和偏向群落，維持高維掠食者的慣性與威嚴。
   - **生態逃跑與夾擊（Evasion）**：當截面迫近，周圍 75px 內的二維節點會感應高維壓迫，打破隊形加速向外散開（Flee）；若遇環體分裂為雙截面，節點會在兩截面形成的狹縫中逃生（雙截面夾擊圍捕）；瀕臨被吞噬時帶有極微幅的幾何資訊共振。
   - **捕食與升維晶格（方案 B 特效）**：落入截面範圍內的二維節點會被包入，在原位漸進淡出時產生**擴散的六邊形幾何拓樸撕裂晶格**、**晶格特徵頂點**與**四向升維投影十字針**，具體展現節點被三維生命抽出平面、帶入高維空間的視覺過程。
   - **世界環境共存**：承襲 M1 的二維幾何生態層，游離點隨資訊流運動、相近連成線、互連圍成面，與截游體形成動態生動的掠食與逃逸互動。
3. **互動控制**：
   - **連接距離／資訊流強度**：透過下方滑桿即時調節二維生態層的聚集密度與流向。
   - **點擊箱內**：在畫布任意位置點擊滑鼠，可投入一組新節點（5 顆）。
   - **暫停／重新生成／儲存截圖**：支援全域暫停、重設物種與即時匯出觀測圖。
