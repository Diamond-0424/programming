# 截游體：超立方體版本

開啟 [index.html](index.html)。完整 p5.js WEBGL 程式：[sketch.js](sketch.js)。

## 形態與觀察

目前沿用真正的三維截面，不是整個四維物體的透視投影。母體是單一超立方體 B=[−a,a]⁴，在 XW、YW、ZW 與 XZ 平面正交旋轉，和 w=s 求交後才保留 xyz 繪製。

外觀以直線、頂點微光與淡平面構成。斜切會有三角形、四邊形、五邊形和六邊形面；四邊形不一定是長方形。母體為凸體，所以非空且非退化的截面為單一凸多面體，不會分裂成獨立碎塊。

三層是同一母體中的固定比例內層（1、0.76、0.52），使用同一旋轉與同一 s。內層只是內部幾何標記，不是額外獨立生物或錯位殘影。

## 數學與實作

16 個 ±a 頂點，只有一個座標不同的兩點構成一條邊，共 32 條邊。固定其中一個座標為 ±a，得到 8 個立方胞。

每条邊 A→B 求 u=(s−Aw)/(Bw−Aw)，0≤u≤1 時交點 P=A+u(B−A)。每個立方胞的共面交點按角度排序成截面多邊形，去重後得到封閉邊界。

平面填色使用三角扇，但只描繪真正的多邊形邊，沒有把填色對角線冒充母體邊。幾何誤差主要來自浮點運算和 1e-7 的去重容差。對完全共面的立方胞，由相鄰胞的截面提供六個外表面。

## 操作与參數

拖曳環視、滾輪縮放；暫停同時凍結四維旋轉與切面位置。重設視角與截圖維持原有按鈕。

| 參數 | 預設 | 用途 |
|---|---|---|
| halfSize | 78 | 超立方體邊長的一半 |
| sliceSpeed | 0.21 | 切面往返速度 |
| rotationSpeed | 0.18 | XW 旋轉速度，其餘旋轉在 rotationAngles 中調整 |
| lineBrightness | 1.2 | 保留前版提高 20% 的線條亮度倍率 |
| shellLevels | [1,0.76,0.52] | 外殼與內部層次；只要外殼可設 [1] |
| slicePosition | 0 | 切面往返的中心位置 |
