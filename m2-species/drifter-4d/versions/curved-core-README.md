# 截游體：四維管狀生物的三維截面

開啟 [index.html](index.html)；完整程式在 [sketch.js](sketch.js)，也可直接貼入 p5.js 編輯器執行（頁面按鈕只在本機 HTML 中提供）。內附 p5.js 1.11.11，不需其他套件或網路。

## 操作

拖曳環視、滾輪縮放；暫停後仍可換角度。重設視角恢復相機，儲存截圖下載 PNG。切面走到母體之外時畫面會暫時空白，這是正常的離開階段。

## 數學模型

母體核心是封閉曲線：

令 q(t)=R+F cos(3t)，核心為 C(t)=(q cos(2t), 0.78q sin(2t), Z[sin(3t)+0.15sin(5t+0.4)], A[0.65sin(t+0.5)+0.35sin(3t)+0.2sin(5t+0.7)])，0 ≤ t < 2π。這是一條兩圈繞行、三次徑向折返的封閉核心。

T 是單位切向量。沿封閉核心的三維法向空間建立圓角超橢球纖維，形成同一個四維管狀母體。局部使用正交基 N、U、V，其中 U.w=V.w=0，N.w=h=√(1−Tw²)。

將局部位移寫成 aN+uU+vV，母體條件為：

|a/r|^p + |(u−k·v)/(r·b)|^p + |v/(r·c)|^p ≤ 1。

p=cornerPower，b/c 是固定在核心各處的寬扁比例，k 是剪切量；都以封閉週期函式定義，不隨幀數隨機變動。這次把舊版圓形法向球改成柔和稜角形狀，已不再是固定歐氏距離半徑的管。

切面 w=s 固定 a=(s−Cw)/h，|a|<r 才有交集；剩餘超橢圓尺度為 ρ=r[1−|a/r|^p]^(1/p)。程式求出對應 u/v 邊界點，再用 P=C+aN+uU+vV 得到四維點，每個點仍符合 Pw=s。

顯示各纖維邊界交線及三層內部輪廓，延續上一版的方法；並非全域最短距離或布林合併後的完整外邊界。母體固定，s 隨時間移動，因此形變、分離和消失仍由求交驅動。稜角是柔和的圓角，並非銳利折線。

## 主要參數

| 參數 | 預設 | 作用 |
|---|---|---|
| coreRadius | 88 | 核心繞行的基準半徑 |
| coreFold | 20 | 核心向內外折返的幅度 |
| lineBrightness | 1.2 | 線條透明度倍率；1 為調整前亮度 |
| tubeRadius | 17 | 法向形體基準尺度 |
| cornerPower | 2.65 | 稜角程度；2 圓滑，2.4～3.2 為柔和稜角 |
| shapeIrregularity | 0.14 | 寬扁、斜切及朝向差異；0 關閉，建議 0～0.25 |
| wAmplitude | 44 | 第四維起伏，影響分離段落 |
| zAmplitude | 32 | 三維中的彎曲程度 |
| slicePosition | 0 | 切面中心；autoSlice=false 時為固定 s |
| sliceSpeed | 0.24 | 自動穿越速度（弧度／秒） |
| autoSlice | true | 是否自動移動切面 |
| coreSamples | 360 | 沿核心的取樣密度 |
| ringSamples | 28 | 每個交圈的點數 |
| lineConnectionDistance | 12 | 鄰接線最長距離，避免跨空缺連線 |
| shellLevels | [1,0.79,0.58] | 外殼與內部兩個等半徑截面層 |

修改上方 PARAMS 後重新載入。密度越高越細緻，但也較耗效能；管半徑過大可能使法向管自交，交集點仍屬此管，但線框不等同經布林合併後的外邊界。

## 函式分工與效能

generate4DCoreCurve 建立封閉核心；sample4DBody 預存法向基底；sliceWith3DSpace 直接求交；project3DToScreen 保留 xyz，螢幕投影由 WEBGL 相機完成；renderCreature 批次繪製線與點。

每幀複雜度 O(層數 × 核心樣本數 × 圈樣本數)，只連參數上相鄰的點，不做全域兩兩距離搜尋。核心與基底只在啟動時建立。線段是離散截面曲面的數值近似；切觸附近以交圈半徑平滑淡入，有限取樣仍可能造成細微離散誤差。
