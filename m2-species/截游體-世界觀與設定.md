## 1. 世界觀（一頁版）

**宇宙被某種高維生命重新啟動。** 重啟後的宇宙不以原子、分子、化學元素為底層，而是由數學與幾何構成。數學不是用來描述宇宙，數學本身就是宇宙。

```
Origin (0,0,0) → 點 → 線 → 面 → 體 → 更高維度
```

- **點**是最基本的存在單位。**線**不是某種材料，而是「兩個點之間建立了關係」。
- 物理仍在，但是由幾何直接產生：位置、距離、方向、邊界、連接、斷裂、碰撞、移動、旋轉、縮放、分裂、合併、維度。
- 一切都能追溯到 **Origin**，這可以是世界裡的神話或信仰。
- **生物的演化不是長器官，而是發展控制自身幾何結構的能力**：連線、斷線、分裂、融合、旋轉、縮放、鏡射、細分、改變拓樸。

### 維度階級（最重要的規則）

| 維度 | 存在 | 這一層的人看到什麼 |
|---|---|---|
| 1D 線 | 只懂前／後；斷裂等於死亡 | |
| 2D 面 | 三角形、四邊形、圓……邊數像生物特徵 | 三維生物穿過時，只看到一連串**截面** |
| 3D 體 | 能直接從「上方」把二維生物拿出封閉邊界 | 四維生物穿過時，只看到**三維截面**（或投影） |
| 4D 以上 | 重啟宇宙的高維生命 | 低維者看不到完整樣子 |

> **低維生命無法主動升維；高維生命可以進入或穿越低維世界。**
> 同一條規則往上推一層：二維觀察者看三維球，看到 `· → o → O → ◎ → O → o → · → 消失`；三維觀察者看四維生物，也只會看到「出現、變形、分裂、消失」的截面。

## 3. 核心概念：牠是誰

**截游體是一個四維生物，我們只能看到牠的影子或切片。**

- 本體是 **24 胞體（24-cell）**：四維空間中的正多胞體，24 個頂點、96 條邊、24 個八面體「胞」。
- 沒有固定外型：同一個本體，觀察方式不同，看到的就不同。

### 兩種「看見牠」的方式

| | 骨架投影（預設） | 真正截面 |
|---|---|---|
| 意義 | 把四維影子投到三維，看見整個骨架 | 一個三維世界切過四維身體，只留下交集 |
| 畫面 | 24 點 + 96 線，內外交錯 | 隨切面位置出現、變形、消失的多邊形 |
| 對應世界觀 | 「看見完整輪廓，但那是影子」 | 「低維者只看到截面：出生、膨脹、縮小、死亡」 |
| 要注意 | 線重疊不代表相連 | 這種母體的截面是凸的，不會分裂成兩塊 |

> 中央截面剛好是**立方八面體**；切到邊緣的胞時是**八面體**。

### 為什麼選 24 胞體
超立方體只有 32 條邊，太簡單；600 胞體線太多，擠在一起；24 胞體用 24 點、96 條真實邊就能做出「密集、尖角、交錯」的骨架，符合參考影片（Alan Becker《Animation vs. Geometry》）的樣子。**【待你決定】** 你自己的選擇理由是什麼，這句我不能代寫。

## 4. 牠怎麼活：行為與捕食

### 4.1 日常
- **自主行為**：依飢餓與體力在「游走／追捕／休息」間切換。是規則加機率，不具意識，不會學習。
- **水母式脈衝推進**：收縮蓄力、噴射、滑行，連續而柔和。
- **四維翻滾**：每隔一段時間或捕食後，繞自身游動方向翻一整圈，同時第四維旋轉暫時加速，24 胞體像花一樣內外翻轉。
- **呼吸**：約 6.4 秒一輪，微光同步起伏。

### 4.2 捕食：開瓣 → 合籠 → 碎解
1. **開瓣**：鎖定獵物後，朝向獵物的前側骨架向外展開成漏斗，後側保留推進。
2. **合籠**：獵物完整進入前方且開得夠大，骨架合攏，獵物在籠內掙扎。
3. **碎解吸收**：獵物的點和線拆成碎片，先散開，再沿螺旋軌跡被吸向核心，拖出殘影。
4. **消化**：略微膨脹、減速，之後回到游動。

> 與世界觀的呼應：你寫過封閉多邊形獵食者「延伸自己的邊界，慢慢包住獵物，邊界一封閉，獵物就進入內部」；開瓣合籠就是這個想法在四維身體上的版本。獵物解體成獨立點，也呼應你設計的點群生物「Disconnect」。

### 4.3 獵物：小生物
- **18 隻、6 種**三維線框形體（四面體、立方體、八面體、三角柱、六角雙錐、細長梭形）。
- 牠們是**三維生命**，剛好是四維截游體吃的對象，符合「高維吞低維」的階級。
- 有求生本能：感應獵者後轉向逃跑，逃跑耗體力，疲倦會變慢；彼此會讓開、會碰撞。
- 被吃掉後，12 秒後從遠處補入新個體。**【待你決定】** 補入在世界裡怎麼解釋？（資訊從維度交會處生成？Origin 的重生？）

## 5. 辨識特徵（報告重點）

目的：不只是一個多胞體，但**不要像現實生物**。每個特徵都有數學依據。

| 特徵 | 看起來 | 數學依據 | 【可能的世界意義，待你改寫】 |
|---|---|---|---|
| **深度明暗** | 離我們近的線亮，遠的暗 | 第四維座標 w 越小越遠 | 讓人感覺到「有一個看不見的方向」 |
| **前導漸層** | 游動方向那邊較亮 | | 牠「朝哪走」 |
| **4 個感測節點** | 4 個互相最遠的頂點，追捕時放大閃動 | 四面體排列，無左右對稱 | 牠感知世界的方式（不是眼睛） |
| **探針** | 從感測節點伸出的細線，追捕時變長並指向獵物 | 沿頂點的四維徑向外延，投影後仍是直線 | 感知的延伸 |
| **內核** | 身體中心的小多胞體，反向旋轉 | 16 胞體 | 能量儲存：吃飽變大變亮，飢餓縮小變暗 |
| **微光面** | 6 個純白發光的三角面，隨追捕與捕食起伏 | 24 胞體有 96 個三角面，挑 6 個分散的 | 能量外露 |
| **六邊形大圓** | 4 個環繞身體的大圓 | 24 個頂點恰好分成 4 組正六邊形，每組共圓（與 Hopf 纖維分解相關） | 身體隱藏的秩序 |
| **Clifford 環面外圍** | 一圈互相鉤環的細弧加一條三葉結形曲線 | 3-球面上的環面；Hopf 纖維鋪滿環面；(2,3) 環面結 | 「更高維度的痕跡」，不是多胞體 |
| **擴散波** | 捕食時大圓向外放大並淡去 | 沿四維徑向外擴約 55% | 進食的餘波 |
| **尾跡** | 身後淡去的位置軌跡 | 真實三維位置歷史 | 牠穿越過的痕跡 |
| **進食閃光** | 捕到獵物時發光面全亮 | | 吸收能量的瞬間 |

**截面模式下的特徵**：不是把投影版搬過去，而是真的求交。曲線（大圓、纖維、結）與切面只剩幾個交點，用空心圓表示；Clifford 環面切出一條線；內核切出自己的截面；發光面直接取截面多邊形。探針、擴散波、光珠只存在於投影，截面下不顯示。

## 6. 環境：養殖箱

- 淡淡的角框（箱子的 8 個角）與約 110 顆緩慢流動的微粒。
- 開瓣吸引、合籠時，會有向外傳播的擾動，約 3 秒消散。
- 微粒只是介質提示，不影響生物行為。
- **【待你決定】** 世界觀裡沒有「養殖箱」。建議的接法：它是**三維的生態層**，對應二維生態層（網格、沉積區）往上一階；角框是那一層的邊界。也可以另有你自己的說法。
